# Security Policy

## Supported Versions

Currently, Agent IAM is in early active development. The latest `0.1.x` release is the only actively supported version.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within Agent IAM, please send an e-mail to the maintainers rather than opening a public issue. We will securely discuss the issue and release a patch as quickly as possible.

Please include:
- A description of the vulnerability.
- Steps to reproduce it.
- Possible mitigations, if known.
