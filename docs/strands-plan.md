# Build `@agentiam/strands` Adapter

This adapter will integrate AgentIAM with **Strands**, the open-source AWS model-driven agent framework. By providing a `wrapGuardedTools` function (or similar), we can intercept tool executions generated by a Strands `Agent` and evaluate them against the AgentIAM policy engine before the native AWS tool logic actually executes.

## Proposed Changes (Pending Clearance)

### 1. `packages/strands` Scaffold
Create the `@agentiam/strands` package with a peer dependency on `strands-agents` (the Strands TypeScript SDK).

### 2. Implement `wrapGuardedTools`
Similar to the Vercel AI SDK and OpenAI adapters, we will build a wrapper that iterates through the provided array of Strands tools. 
- Strands tools are strongly typed and often rely on Zod schemas. 
- We will dynamically override the tool's execution/handler method.
- When invoked, we will call `iam.guard()`.
- If `allow`, we execute the original Strands tool handler.
- If `approval_required` or `clarification_required`, we will return a structured JSON string containing the `checkpointId` and status, allowing the Strands agent to pause gracefully.

### 3. Implement `resumeGuardedTool`
A utility to easily resume a paused Strands tool execution once a human approves the checkpoint via the AgentIAM persistence store.

### 4. Tests and Example
- Add `node:test` coverage for the adapter mirroring our rigorous Vercel and LangGraph tests.
- Create `examples/strands-terminal` to demonstrate a complete agent loop using Strands + AgentIAM.

## Verification Plan
We will verify that the wrapped tools correctly intercept execution, that the Strands agent correctly halts when given an `approval_required` JSON payload, and that resuming the checkpoint correctly executes the native tool.
